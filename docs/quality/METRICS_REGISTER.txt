SECTION 1: OCR METRICS
================================================================

OCR-001 | OCR | Character Error Rate (CER)
  Description: Rate of incorrectly recognized characters in extracted text
  Formula: (substitutions + deletions + insertions) / total_reference_characters
  Target: < 0.05 (5%)
  Blocking Threshold: > 0.20 (20%)
  Measurement Frequency: Every OCR model or preprocessing pipeline change
  Current Baseline: NOT MEASURED

OCR-002 | OCR | Word Error Rate (WER)
  Description: Rate of incorrectly recognized words in extracted text
  Formula: (S + D + I) / N where S=substitutions, D=deletions, I=insertions, N=total words
  Target: < 0.10 (10%)
  Blocking Threshold: > 0.30 (30%)
  Measurement Frequency: Every OCR model or preprocessing pipeline change
  Current Baseline: NOT MEASURED

OCR-003 | OCR | Text Extraction Completeness
  Description: Percentage of expected text regions successfully extracted
  Formula: extracted_regions / total_expected_regions
  Target: > 0.90 (90%)
  Blocking Threshold: < 0.70 (70%)
  Measurement Frequency: Every OCR pipeline change
  Current Baseline: NOT MEASURED

SECTION 2: DOCUMENT CLASSIFICATION METRICS
================================================================

DC-001 | Document Classification | Accuracy
  Description: Percentage of documents classified into the correct category
  Formula: correct_classifications / total_documents
  Target: > 0.90 (90%)
  Blocking Threshold: < 0.75 (75%)
  Measurement Frequency: Every classification model or prompt change
  Current Baseline: NOT MEASURED

DC-002 | Document Classification | Precision (per class)
  Description: Of documents classified as class X, what fraction were truly class X
  Formula: TP / (TP + FP) per class, then macro-averaged
  Target: > 0.85 macro-average
  Blocking Threshold: < 0.70 for any safety-critical class
  Measurement Frequency: Every classification model or prompt change
  Current Baseline: NOT MEASURED

DC-003 | Document Classification | Recall (per class)
  Description: Of documents truly class X, what fraction were classified as X
  Formula: TP / (TP + FN) per class, then macro-averaged
  Target: > 0.85 macro-average
  Blocking Threshold: < 0.70 for any safety-critical class
  Measurement Frequency: Every classification model or prompt change
  Current Baseline: NOT MEASURED

DC-004 | Document Classification | F1 Score
  Description: Harmonic mean of Precision and Recall
  Formula: 2 * (Precision * Recall) / (Precision + Recall), macro-averaged
  Target: > 0.85
  Blocking Threshold: < 0.70
  Measurement Frequency: Every classification model or prompt change
  Current Baseline: NOT MEASURED

DC-005 | Document Classification | Confusion Matrix
  Description: Full N×N matrix of predicted vs actual classes
  Formula: Count matrix
  Target: Diagonal-dominant; off-diagonal elements documented
  Blocking Threshold: Any safety-critical misclassification > 10%
  Measurement Frequency: Every classification change
  Current Baseline: NOT MEASURED
