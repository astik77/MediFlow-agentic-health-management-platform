================================================================
HOW TO USE THIS TEMPLATE
================================================================
1. Copy this template to docs/quality/reports/
2. Name the file: TEST_REPORT_NNN_YYYY-MM-DD.txt
   where NNN is a sequential 3-digit number
   Example: TEST_REPORT_001_2026-11-20.txt
3. NEVER overwrite an existing report
4. If a test is re-run, create a NEW report with a new number
5. Fill in every field — use "N/A" for non-applicable fields
6. Use "NOT RUN" for tests not executed (do NOT leave blank)
