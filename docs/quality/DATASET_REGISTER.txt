MEDIFLOW — DATASET REGISTER
============================
Version: 1.0.0
Created: 2026-11-16
Phase: 0 (Foundation)

================================================================
CRITICAL WARNING
================================================================
Real patient medical data must NEVER appear in this register.
All datasets listed here use synthetic data only.
Test datasets must NOT be shared publicly or committed with
patient-identifying information of any kind.

================================================================
PURPOSE
================================================================
This register tracks all synthetic datasets used for evaluating
MEDIFLOW's document intelligence, OCR, extraction, and AI
capabilities. Each dataset has a unique identifier, description,
ground-truth format, and versioning information.

================================================================
DATASET ID FORMAT
================================================================
  DS-<TYPE>-<NNN>
  
  Types:
    LAB   : Laboratory reports
    PRES  : Prescriptions
    DISC  : Discharge summaries
    IMG   : Imaging reports
    CONS  : Consultation notes
    MIX   : Mixed document types
    RAG   : RAG evaluation queries
    SAFE  : Safety test cases
    SEC   : Security test cases

  Example: DS-LAB-001, DS-RAG-001, DS-SEC-001

================================================================
GROUND TRUTH FORMAT
================================================================
Each dataset has a corresponding ground-truth file:
  test-data/synthetic/<DATASET_ID>/documents/  : Source files
  test-data/synthetic/<DATASET_ID>/ground-truth/ : Expected outputs

Ground truth files are JSON with schema:
  {
    "dataset_id": "DS-LAB-001",
    "document_id": "doc-001",
    "document_type": "laboratory_report",
    "expected_observations": [
      {
        "test_name": "Hemoglobin",
        "value": "13.5",
        "unit": "g/dL",
        "reference_range": "12.0-16.0",
        "flag": null,
        "date": "2026-11-01"
      }
    ],
    "expected_patient_info": { ... },
    "expected_dates": { ... }
  }

================================================================
DATASET STATUS KEY
================================================================
  PLANNED    : Dataset defined but not yet created
  IN_PROGRESS: Dataset being built
  COMPLETE   : Dataset ready for use
  DEPRECATED : Dataset retired (reason in notes)
